# CompEditor 0.2.3（build 859）

起動時に更新の有無をバックグラウンドで確認し、新しい版があればアプリケーションメニューに知らせます。起動や編集を待たせず、確認に失敗してもダイアログは表示しません。アプリのダウンロード・インストールは、既存の手動更新と署名検証を経て行います。

利用統計のバックグラウンド送信を追加しました。送信項目、送信先、ランダムIDの性質、保存先・保持期間と削除の契機は[利用統計について](https://github.com/KDU-i/CompEditor/blob/v0.2.3/Release/USAGE_STATISTICS.md)を参照してください。コード本文、入力内容、ファイル名・パス、氏名・メール、ハードウェアIDは統計に含めません。Copilotのコード送信に必要な既存の同意は別の仕組みです。

macOS 26以降・Apple Silicon向けです。従来と同じad-hoc署名とSparkle Ed25519署名を使い、Developer ID署名・Apple公証は行いません。非公式のCotEditor派生版として、既存のライセンスと帰属表示を保持します。
