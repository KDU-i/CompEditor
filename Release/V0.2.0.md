# v0.2.0 local release preparation

Version 0.2.0, build 854, macOS 26+, arm64. No remote push, tag or release publication is included. The host release is built as optimized Release in fresh directories, with coverage/instrumentation disabled, anonymous prefix maps and stripped host debug records. Distribution contains only the app, reviewed exact-tree source, pinned corresponding sources, provenance, required notices and checksums; build directories, XCArchive metadata, dSYMs, logs, screenshots, personal test documents and auth caches are excluded.

The existing KDU-i anonymous GitHub noreply identity was checked against the account ID/login and a public commit. Use that same identity for author and committer for the local release commit only. No global Git changes or history rewriting. Preserved upstream authors, copyrights, licenses, and public sample attribution are retained.

Build recipe: create an isolated temporary index from HEAD, add only reviewed release paths, and write its tree. Set RELEASE_SOURCE_TREE to that tree when invoking build-release-candidate.sh with fresh source/build paths and explicit pinned package/server/Node/JDK/Copilot inputs. Audit app and sanitized source, package to temporary ZIP, inspect completed ZIP, and only then finalize names/checksums. Commit exactly the reviewed index and verify commit^{tree} equals that source tree. Do not include private build logs or local reports in Git.

Privacy audit must cover all current source files and added diff, commit metadata, filename/link targets, Mach-O slices and compressed LLVM records, nested ZIP/JAR contents, actual distribution archives and sidecars. Supplement the bounded scanner with owner-identifier/email/affiliation checks whose private patterns remain outside the repository. Upstream hash-scoped reviewed exceptions are permitted only for existing public attribution/sample material and fixed official dependencies, never for the owner's home or credentials. Review any new official Copilot binary findings before extending exceptions.

Reproducibility: dependency versions/input hashes and source tree are recorded; ZIP member timestamps are fixed and metadata excludes host UID/xattrs. Same-input packaging must reproduce the ZIP hash. Independent full rebuild byte-for-byte reproducibility is not claimed; record exact toolchain/version separately. Reaudit after signing, rebuilding, changing assets or metadata.

Publication remains gated on final owner approval of exact assets, noncommercial original-artwork conditions, equal-access corresponding sources, clean-machine/Gatekeeper verification and signing/notarization decisions. macOS 26, Intel, real NES candidate acceptance, physical IME/multi-caret stress and exhaustive wrapped geometry remain unverified. Existing v0.1.0 artifact privacy findings are documented in PRIVACY_REBUILD.md; no historical tag/asset removal or force push is performed here.

Updater added before release commit: Sparkle 2.10.0 standard updater/controller, kept alive for the application. The dedicated owner-approved public key and HTTPS GitHub feed are separate from upstream CotEditor configuration. Require signed feed with no expiration fallback, verify archive before extraction, disable automatic checks/install and profiling. Feed checks transmit network IP/app+Sparkle version; no document content or custom device identity is included. Only fixed-version KDU-i/CompEditor GitHub Release ZIPs are accepted. Unsaved documents defer install/resume; standard installer handles stage-dependent cancellation. No rollback promise.

The dedicated Ed25519 key was generated with official Sparkle tools under owner approval and is retained only in Mac Keychain. Its public half and the approved HTTPS appcast URL are embedded; hosting remains unpublished. Actual archives/feeds are signed locally with the dedicated account without exporting the private key. Secret-key/CI/hosting/account changes are separate actions. Any Developer ID signer identity may be visible in certificates/metadata and must be reviewed against anonymity goals. Old builds without this updater need one initial manual installation.
