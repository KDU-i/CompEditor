# NES 0.3.1 対応・検証計画

基準: CompEditor 5332757、VS Code 9a59550、Copilot Chat 5863f5a。公開コードは挙動の参考としコピーしない。非公開モデル/配信実験/設定依存の完全一致は対象外。

|項目|対応|検証|
|---|---|---|
|01 トリガー調停|既存inline優先fallbackを維持。表示中NESを保持|policy/RPC回帰|
|02 デバウンス|既存50msと重複抑制を維持|診断privacy/重複試験|
|03 履歴|観測した直前snapshot/現在文書のみを維持|incremental/実サービス。提供側履歴は残差|
|04 カーソル寿命|同一文書の空選択移動でNES保持|同行/遠距離/選択/複数caret|
|05 対象位置|対象rangeへ描画・ガター移動指標|画面内外/別URI拒否|
|06 全差分|形状別の色付き差分表示|挿入/置換/削除/複数行|
|07 行内挿入|緑背景の行内挿入と矢印|合成挿入描画|
|08 単語置換|旧語赤背景と直下の緑の置換|合成Hello→Goodbye|
|09 適用形状|単一range正規化を維持、実差分へ縮小|全形状/CRLF/Unicode|
|10 Tab|対象行±1と画面内連続採用|同行別列/近接/遠距離/連続|
|11 優先順位|NESのインデント/通常補完優先|空行Tab/既存inline回帰|
|12 Esc|取消ガードを維持|表示/IME/要求中|
|13 入力rebase|対象前後と整合する部分入力を保持|整合/不整合/対象前/削除|
|14 末尾caret|最小実差分末尾へ折り畳み|挿入/削除/広いrange|
|15 Undo|採用のundo後自動生成を抑制|undo/redo/入力再開/分離|
|16 連続候補|採用後要求と連続採用状態|RPC/連続Tab。提供側先読みは残差|
|17 IME|全安全ガード維持|marked text/複数caret|
|18 viewport|スクロール/resizeで再配置し保持|狭幅/画面外/スクロール|
|19 設定|既存独立フラグと接続OFF維持|policy/menu回帰|
|20 異常応答|既存version/epoch/URI拒否を維持|malformed/timeout/unsupported/stale|
