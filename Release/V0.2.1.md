# CompEditor 0.2.1 (857)

GitHub Copilotの既存認証を起動時に確認し、正常終了ではsignOutせずstdio LSPのshutdown/exitで閉じます。新しいOAuth認可は本人操作です。アプリは資格情報を取得・記録せず、接続ON/OFFと任意の送信同意の記憶だけをBoolで保存します。

文書・周辺コードのGitHubへの送信は明示的なONと同意の後に始まります。「このMacで送信同意を記憶」は既定でOFFです。記憶しない場合は次回起動で同意を確認します。OFF中は文書同期を停止します。ネットワークや一般的なサーバーエラーだけでは認証切れと表示しません。

現在のAI候補が実際に表示されている間は通常候補の一覧・選択・タイマー・未完了要求を取り消し、Tabで表示中のAI候補を採用します。AIの読み込み中、空の応答、失敗時は通常補完を使えます。Esc、カーソル移動、編集・revision変更、IME変換中は古い候補を採用しません。通常補完の明示操作はAI候補を閉じます。これは利用者が希望したUI方針で、VS Codeの標準ポップアップ優先動作とは異なります。

## 検証範囲

実認証の既存状態を公式CLSのcheckStatusと正常終了だけで3回確認しました。この確認では新しいOAuth認可や文書送信を行っていません。候補表示・Tab・部分採用・Undo・空/失敗応答・取消・同意記憶のGUIは通信しない独立アプリで確認します。実機日本語IMEと正式版の更新インストール・再起動は未確認です。IME変換ガードはAppKitテストで検証します。

配布物には従来のSparkle Ed25519公開鍵、署名済みfeed/ZIP、手動更新確認を継続します。Developer ID署名・公証は行っていません。第三者ライセンス、ソース、元の帰属、作品の非商用条件は同梱資料を参照してください。
